# AI Auto-Landing Page Publisher

Hệ thống AI tự động tạo nội dung bán hàng chuẩn chuyển đổi và xuất bản Landing Page lên GitHub Pages chỉ với 1 click.

## Cấu Trúc Dự Án
- `frontend/`: Giao diện Web quản lý (HTML, Tailwind CSS, JavaScript Vanilla, App Shell).
- `backend/`: Máy chủ API xây dựng bằng FastAPI, tích hợp Google Gemini AI, MySQL và GitHub API.
- `docs/`: Tài liệu đặc tả, kiểm thử và hướng dẫn triển khai.
